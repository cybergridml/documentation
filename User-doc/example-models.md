#  Example Model

The examples models are hosted in the following GitHub repository:

[CybergridML Models – GitHub](https://github.com/cybergridml/cybergrid-models)

##  Steps to Test an Example Model

In our case, we will use the following model:

`SCADA_Centralised_Decentralised-CRAS.sysml`

To test this example, a [CybergridML release](https://github.com/cybergridml/cybergrid-modeller/releases) is required. 
The corresponding `.sysml` file must then be imported into the CybergridML project.

Follow these steps:

###  Open a CybergridML Project

Start by opening or creating a **CybergridML** project using the available release.
![CybergridML project](../icons/cybergrid_project.png)
<p align="center">
  <em>Figure 1 — CybergridML project</em>
</p>

###  Download the Example Model

Download the SysML file corresponding to the example from the GitHub repository:

`SCADA_Centralised_Decentralised-CRAS.sysml`

Then, import this file into the CybergridML project.

![CybergridML project](../icons/upload-exemple.png)
<p align="center">
  <em>Figure 2 — Upload exemple</em>
</p>

###  Visualize the Elements Contained in the Views

Once the model has been imported, the different model elements can be viewed through the **views** available in the different packages.

![CybergridML project](../icons/CFA-expl.png)

*Figure 2 — CFA for example*


### Graphical Visualization of the Model

To visualize the model graphically, it is necessary to create a view in each `view` package.
This step makes it possible to visually verify the structure and the different elements of the model.
We will continue with the CFA view to demonstrate how graphical views can be created.
